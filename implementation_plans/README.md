# Implementation Plans

This directory indexes the instructions and plans used during implementation. It is a convenience entry point and does not replace the repository's authoritative requirements, phase records, validation evidence, or closure decisions.

Name future instruction files with a phase or task identifier and a short kebab-case purpose, such as `phase-4-accessibility-audit.md`. Keep each document focused and link its final validation record when the work closes.

## Archived Supplied Instructions

These files preserve the user-supplied source instructions for audit history. Their bodies are archived as supplied and are not current execution requests or canonical status records. Original paths, baselines, and phase boundaries may be stale; use `REQUIREMENTS.md` and the corresponding records under `C/` when they differ.
